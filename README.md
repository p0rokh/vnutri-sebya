# Внутри себя

Информационный сайт с тестом-самопроверкой на риск расстройств пищевого поведения (РПП) — продукт индивидуального проекта по вероятности и статистике (9 класс, МАОУ Лицей 200).

Тест из 33 вопросов считает показатель риска по модели проекта
**R = 0.25·F1 + 0.25·F2 + 0.3·F3 + 0.2·F4** (когнитивные установки, образ тела, пищевое поведение, внешние факторы) целиком в браузере. После прохождения ответы и результат сохраняются анонимно (без имени, контактов и IP) для статистики проекта.

## Структура

- `site/` — сам сайт: чистые HTML/CSS/JS, без сборки и внешних зависимостей.
- `docs/` — документация процесса: ТЗ, аналитика (модель подсчёта, проверка контактов помощи), дизайн-система, план реализации.
- `tests/` — проверки: `quiz.test.js` (юнит-тесты формулы, Node), `smoke.html` и `probe-*.html` (интеграционные прогоны в headless Chrome).
- `PLAN.md` — общий план проекта по этапам.

## Как запустить

Открыть `site/index.html` в браузере — этого достаточно, сайт полностью статический.

Тесты формулы (node или deno):

```bash
node tests/quiz.test.js
deno run --unstable-detect-cjs --allow-read=. tests/quiz.test.js
```

Интеграционный смоук (четыре прохождения теста: три уровня риска и проход с пропусками):

```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new \
  --allow-file-access-from-files --virtual-time-budget=8000 \
  --dump-dom "file://$PWD/tests/smoke.html" | grep -o "<title>[^<]*</title>"
```

## Публикация

Сайт публикуется на GitHub Pages из ветки `gh-pages` (содержимое папки `site/`). Обновление после правок в `main`:

```bash
git subtree push --prefix site origin gh-pages
```

Сайт закрыт от индексации поисковиками (`robots.txt` + `noindex`) — доступ по прямой ссылке.
