# Техзадание: сайт «Внутри себя»

Продукт индивидуального проекта Алисы Сидельниковой (8А, МАОУ Лицей 200) по вероятности и статистике «Расчёт вероятности появления у человека расстройств пищевого поведения».

## 1. Цель продукта

Информационный сайт, который:
1. Даёт подросткам понятную и бережную информацию о расстройствах пищевого поведения (РПП).
2. Позволяет анонимно пройти тест-самопроверку из 29 вопросов и получить оценку вероятности риска по математической модели проекта (формула R с четырьмя факторами).
3. Подсказывает, что делать дальше и куда обращаться за помощью.

Сайт наглядно демонстрирует применение теории вероятностей и статистики — это основа защиты проекта.

## 2. Аудитория и сценарий использования

- Школьники ~13–17 лет, а также их близкие и учителя.
- Заходят по прямой ссылке от автора проекта (сайт не индексируется поисковиками — так задумано).
- Устройства: в первую очередь смартфоны, во вторую — школьные ноутбуки/десктопы.
- Типичный сценарий: зашёл → почитал о РПП → прошёл тест (10–15 минут) → увидел уровень риска и объяснение → посмотрел рекомендации/техники → при необходимости нашёл телефон помощи.

## 4. Функциональные требования

### Тест (ядро продукта)

- **Т1.** 29 вопросов из `input/Вопросы.txt`, по одному на экране. Прогресс: «Вопрос N из 29» + полоса + процент.
- **Т2.** Ответы — шкала из 4 вариантов с подписями-пояснениями (как в макете: «Почти никогда … Почти всегда»). Исключения: у вопроса 28 — 5 вариантов из файла («нет таких … 5+ человек»), у вопроса 29 — шкала влияния из 4 вариантов. Точные баллы всех вариантов — в документе «Аналитика».
- **Т3.** «Далее» активируется после выбора ответа. «Назад» возвращает к предыдущему вопросу с сохранённым выбором. «Выйти из теста» — с лёгким встроенным подтверждением (не системный `alert`), выход на главную.
- **Т4.** Подсчёт риска — целиком в браузере по модели проекта: R = 0.25·F1 + 0.25·F2 + 0.3·F3 + 0.2·F4, уровни: низкий / средний / высокий. Никаких отправок данных куда-либо.
- **Т5.** Экран результата: уровень с цветовым кодом (зелёный/жёлтый/розовый), значение R с двумя знаками (например, «2.27 из 4»), разбивка по факторам F1–F4 (мини-полоски со значениями), блоки «Что это значит», «Важно помнить», «Что дальше», «Куда обратиться». Для высокого риска телефоны помощи — на видном месте.
- **Т6.** «Пройти тест заново» — полный сброс и старт с первого вопроса.
- **Т7.** Вместо кнопки «Сохранить результат» из макета — «Распечатать результат» (`window.print`, ничего не хранит). Карточка «Дневник настроения» из макетов убирается (требует хранения данных).
- **Т8.** Обновление/закрытие страницы сбрасывает прохождение — это осознанное следствие решения «ничего не храним», упоминается в интро теста.

### Контентные страницы

- Статичный контент по контент-плану из «Аналитики», вёрстка по референсам.
- На страницах теста и результата — дисклеймер «тест не ставит диагноз и не заменяет консультацию специалиста».
- Внизу каждой страницы — блок «Если тяжело прямо сейчас» со ссылкой на раздел помощи.

## 5. Нефункциональные требования

- **Технологии:** чистые HTML/CSS/JS, без сборщиков, фреймворков и библиотек. Никаких CDN и внешних зависимостей: шрифты — локальные файлы (с открытой лицензией) или системные.
- **Работа:** сайт полностью работает как с хостинга, так и при открытии файлов локально (`file://`).
- **Адаптивность:** от 360px (смартфоны) до десктопа.
- **Анимации:** простые и ненавязчивые — появление блоков при скролле, переходы между вопросами, анимация прогресс-бара. Уважаем `prefers-reduced-motion`.
- **Производительность:** без тяжёлых ресурсов, изображения оптимизированы, страница открывается быстро даже на слабом школьном ноутбуке.
- **Доступность (базовая):** семантичная разметка, alt у изображений, достаточный контраст текста, работа с клавиатуры в тесте, aria-атрибуты у прогресса и вариантов ответа.

## 6. Безопасность и приватность (формально)

- `robots.txt`: `User-agent: *` + `Disallow: /` — роботы по сайту не ходят.
- `<meta name="robots" content="noindex, nofollow">` на каждой странице.
- Ноль сбора данных: нет форм отправки, кук, localStorage, аналитики, внешних трекеров и запросов к сторонним серверам.
- Внешние ссылки — только HTTPS, с `rel="noopener"`.
- HTTPS обеспечивается хостингом (GitHub Pages — из коробки).

## 7. Требования к контенту

- Тон — бережный, поддерживающий, на «ты», без запугивания и оценочности (ориентир — тексты референсов).
- Формулировки вопросов теста берутся из `Вопросы.txt` без изменений (валидность модели важнее гладкости). Единственное допустимое отличие — приведение обращения к «ты» в q28–q29 («в вашем окружении» → «в твоём окружении»), смысл не меняется.
- Интро теста предупреждает: вопросы личные, ответы никто не увидит, честность повышает точность.
- Телефоны и ресурсы помощи — только проверенные по официальным источникам (проверка на этапе аналитики, источники фиксируются в документе). У каждого номера — подпись, кому он принадлежит и режим работы.

## 8. Допущения и адаптации модели (важно для защиты проекта)

- Формула презентации рассчитана на 30 вопросов; опросник содержит 29. Адаптация: F4 = среднее по q16–q29 (вместо q16–q30). Веса факторов и пороги уровней не меняются.
- Шкала ответов 1–4 (подтверждается слайдом «3.16 из 4»). Границы уровней: R < 1.5 — низкий, 1.5 ≤ R < 2.5 — средний, R ≥ 2.5 — высокий.
- Вопрос 29 в файле не имеет вариантов ответа — шкала влияния 1–4 добавлена нами (фиксируется в «Аналитике» как дополнение).
- В макете теста указано «Вопрос 1 из 25» — осознанное расхождение, у нас 29.

## 9. Критерии приёмки

1. Все страницы из раздела 3 (9 HTML-файлов; результат — экран внутри `test.html`) свёрстаны в стиле референсов и корректно выглядят на 360px и на десктопе.
2. Тест проходится от начала до конца; «Назад» и перезапуск работают; все три уровня риска достижимы.
3. R на контрольных наборах ответов совпадает с ручным расчётом (все «1» → 1.00 низкий; все максимумы → 4.00 высокий; граничные 1.5 и 2.5 попадают в уровни по конвенции).
4. В DevTools нет ни одного запроса к сторонним доменам; куки и localStorage пусты.
5. `robots.txt` и `noindex` на месте.
6. Все телефоны помощи проверены, источники зафиксированы.

## 10. Вне рамок (не делаем)

Хранение чего-либо (сервер, localStorage, куки), личные кабинеты, аналитика и метрики, CMS, мультиязычность, SEO (сознательно анти-SEO), офлайн-режим через service worker, «Дневник настроения», реальные страницы соцсетей.
