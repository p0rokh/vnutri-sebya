
## 3. Модель подсчёта (опросник v2, октябрь 2026)

Итоговый опросник — `input/Вопросы-v2.txt`: 33 вопроса в шести разделах. 32 задаются подряд, вопрос 33 (оценка проекта) — на экране результата. В подсчёт риска входят только вопросы 3–31; вопросы 1, 2, 32, 33 собираются для статистики.

### 3.1. Шкалы ответов

**Стандартная шкала (вопросы 3–28):**

| Балл | Вариант | Подпись |
|---|---|---|
| 1 | Никогда | Такого не бывает |
| 2 | Редко | Бывает очень редко |
| 3 | Иногда | Время от времени |
| 4 | Часто | Такое происходит регулярно |
| 5 | Почти всегда | Это про меня |

**Коды нечисловых ответов** (в подсчёт не входят, в статистике видны отдельно): `-1` «Предпочитаю не отвечать», `-2` «Затрудняюсь ответить».

**Вопросы 17–21** (чувствительные: рвота, слабительные, пропуск еды, голодание, желание «избавиться») — стандартная шкала + шестой вариант «Предпочитаю не отвечать» (`-1`).

**Вопрос 29** «В семье есть люди с проблемами питания или веса»: Да = 5 · Нет = 1 · Затрудняюсь ответить = -2 · Предпочитаю не отвечать = -1. *(Баллы Да/Нет — открытый вопрос, `Открытые-вопросы.md` §2.)*

**Вопрос 30** «Сколько человек в твоём окружении имеют проблемы с отношением к еде?»: Ни одного = 1 · 1–2 человека = 2 · 3–5 человек = 4 · Более 5 человек = 5 · Затрудняюсь ответить = -2. *(Баллы — открытый вопрос, §3.)*

**Вопрос 31** «Насколько их поведение влияет на тебя?»: Совсем не влияет = 1 · Слабо = 2 · Умеренно = 3 · Сильно = 4 · Очень сильно = 5 · Затрудняюсь ответить = -2.

**Без баллов:** q1 пол (Женский / Мужской / Другой вариант / не отвечать), q2 возраст (До 14 / 14–17 / 18–25 / 26+ / не отвечать), q32 диагноз РПП (6 вариантов, из них «затрудняюсь» и «не отвечать»), q33 оценка проекта (6 вариантов, последний — «затрудняюсь»).

**Среднее по фактору считается по отвеченным вопросам:** ответы с кодами `-1`/`-2` исключаются и из суммы, и из знаменателя. Например, если q17–q21 пропущены, F3 = (q11+…+q16)/6, F4 = (q22+…+q31)/10.

### 3.3. Формула и уровни

**R = 0.25·F1 + 0.25·F2 + 0.3·F3 + 0.2·F4**

Сумма весов = 1, каждый фактор ∈ [1; 5] ⇒ R ∈ [1.00; 5.00]. Отображение: 2 знака после запятой, «R из 5».

| Уровень | Условие (временно) | Цвет |
|---|---|---|
| Низкий риск | R < 1.67 | зелёный |
| Средний риск | 1.67 ≤ R < 3.00 | жёлтый |
| Высокий риск | R ≥ 3.00 | розовый/красный |

⚠️ Пороги **временные**: пропорциональный перенос границ 1.5/2.5 со шкалы 1–4 на шкалу 1–5. Итоговые значения решает Алиса — `docs/Открытые-вопросы.md` §1; в коде это одна константа `LEVELS` в `site/js/quiz.js`. Конвенция границ сохраняется: точное значение порога относится к более высокому уровню.

### 3.4. Адаптация модели (для защиты проекта)

Формула презентации рассчитана на 30 вопросов со шкалой 1–4. Первая версия сайта (сентябрь 2026) использовала 29 вопросов: F4 усреднялся по 14 вопросам, пороги 1.5/2.5, «R из 4». Контрольная сверка со слайдом 12/13: средние F1=2.1, F2=2.5, F3=2.4, F4=2.0 дают R = 2.27 — ровно значение презентации, модель реконструирована верно.

Итоговый опросник (октябрь 2026) расширен до 33 вопросов: добавлены вводные вопросы о поле и возрасте, вопрос о подтверждённом диагнозе и оценка проекта (в подсчёт не входят); шкала ответов стала 5-балльной (Никогда … Почти всегда); чувствительные вопросы 17–21 можно пропустить, у q29–q31 есть «затрудняюсь ответить». Среднее остаётся средним — веса факторов не меняются; пропуски исключаются из среднего; пороги уровней перенесены на новую шкалу пропорционально и ждут решения (§3.3).

## 4. Модель данных теста (`js/quiz.js`)

```js
var QUIZ_VERSION = "2";
var CODES = { DECLINE: -1, UNSURE: -2 };               // «не отвечать» / «затрудняюсь»
var OPT_DECLINE = { code: -1, label: "Предпочитаю не отвечать", hint: "…" };
var OPT_UNSURE  = { code: -2, label: "Затрудняюсь ответить" };
var SECTIONS = { 1: "Общая информация", 2: "Отношение к еде и собственному телу", /* … */ 6: "Рефлексия и оценка проекта" };

var SCALE_DEFAULT = [ { value: 1, label: "Никогда", hint: "…" }, /* … */ { value: 5, label: "Почти всегда", hint: "…" } ];
var SCALE_SKIPPABLE = SCALE_DEFAULT.concat([OPT_DECLINE]);

// 32 вопроса потока: { id, section, factor: "F1"…"F4" | null, text, options?, skippable? }
var QUESTIONS = [
  { id: 1, section: 1, factor: null, text: "Укажите ваш пол", options: [ { label: "Женский" }, /* … */ OPT_DECLINE ] },
  { id: 3, section: 2, factor: "F1", text: "Я думаю о еде большую часть дня" },        // options нет → SCALE_DEFAULT
  { id: 17, section: 2, factor: "F3", text: "Я вызываю рвоту после еды", options: SCALE_SKIPPABLE, skippable: true },
  { id: 29, section: 3, factor: "F4", text: "…", options: [ { value: 5, label: "Да" }, { value: 1, label: "Нет" }, OPT_UNSURE, OPT_DECLINE ] },
  // …
];
var RATING_QUESTION = { id: 33, section: 6, factor: null, text: "…", options: [ /* 5 вариантов */ OPT_UNSURE ] };
var ALL_QUESTIONS = QUESTIONS.concat([RATING_QUESTION]);

function optionsFor(q) { return q.options || SCALE_DEFAULT; }
function scoreOf(opt)  { return typeof opt.value === "number" ? opt.value : opt.code; }

var WEIGHTS = { F1: 0.25, F2: 0.25, F3: 0.3, F4: 0.2 };
var LEVELS  = { mediumFrom: 1.67, highFrom: 3.0 };     // ВРЕМЕННО, см. Открытые-вопросы.md §1

// API: computeResult(answers: Map<id, балл|код>) → { R, factors: {F1..F4}, level }
//      коды (<0) исключаются из среднего; нет ответа на вопрос с фактором → ошибка
```

В интерфейсе хранится индекс выбранного варианта (а не балл) — так «Назад» восстанавливает выбор, а на сервер уходит именно индекс: баллы и пороги можно пересматривать без пересбора данных. Тексты вопросов — дословно из итогового списка (обращения «вы»/«ты» в нём смешаны, см. `Открытые-вопросы.md` §4).

## 5. Контент-план страниц

Тексты ниже — итоговые для коротких блоков (основа — референсы). Для статей и «Рекомендаций» — структура и тезисы, финальные тексты пишутся на этапе MVP.

### 5.1. Главная (`index.html`)

1. **Hero**: плашка «Ты важен. Твои чувства имеют значение» · заголовок «Понимание — первый шаг к поддержке» · текст «Этот сайт поможет тебе узнать больше о расстройствах пищевого поведения, пройти тест и получить рекомендации» · кнопки «Пройти тест» / «Узнать больше».
2. **Три плашки доверия**: Анонимно (ответы никто не увидит) · Безопасно (ничего не сохраняется) · Поддержка рядом (ты не один(на)).
3. **Что такое РПП** (кратко) + 4 карточки: «Это не про выбор», «Это касается каждого», «Помощь работает», «Ты не один(на)» + кнопка «Подробнее» → about.html.

### 5.2. О РПП (`about.html`)

1. Заголовок «Что такое РПП?» + определение (мягкая формулировка из референса: «серьёзные психические состояния, которые влияют на отношение к еде, телу и себе; это не выбор и не слабость характера») + вынос «РПП — это не про еду. Это про эмоции, контроль, страхи».
2. **Основные виды** — 4 карточки: анорексия, булимия, компульсивное переедание, другие формы (орторексия, дранкорексия) с бережными описаниями по референсу.
3. **На что стоит обратить внимание** — 6 сигналов (навязчивые мысли о еде; чувство вины после еды; изоляция и перепады настроения; резкие колебания веса и «диеты»; чрезмерные тренировки как «отработка» еды; отказ от любимых продуктов и встреч).
4. **Коморбидность** (из презентации, упрощённо): РПП часто соседствуют с депрессией, тревожными расстройствами, ОКР, зависимостями — ещё одна причина не откладывать поддержку.
5. **Мифы и правда** — 3 пары из референса (не только у девушек-подростков; не всегда про худобу; не каприз).
6. CTA «Ты не один(а)» → тест.

### 5.3. Тест (`test.html`) — интро и вопросы

Интро: заголовок «Самопроверка», текст «Этот тест помогает лучше понять своё эмоциональное и пищевое поведение. Он не ставит диагноз и не заменяет консультацию специалиста», плашки «Займёт 10–15 минут» / «Анонимно: сохраняем только ответы и результат, без имени и контактов» / «Только для самопонимания», предупреждение «Некоторые вопросы личные. Отвечай честно — так результат будет точнее. Если обновить страницу, прогресс начнётся заново», обязательный чекбокс согласия на анонимное сохранение ответов, кнопка «Начать».
Под вопросами — постоянная плашка «Важно помнить: честные ответы помогут получить более точный результат».

### 5.4. Результат (3 состояния)

Общее: «Спасибо, что прошёл(ла) тест. Это важный шаг к тому, чтобы лучше понять себя» + дисклеймер «не диагноз». Блок числа: «Твой показатель: R из 4» + мини-полоски факторов F1–F4 с подписями (когнитивные установки / образ тела / пищевое поведение / внешние факторы). Кнопки: «Пройти тест заново», «Распечатать результат».

- **Низкий (зелёный)**: «Твои ответы не указывают на выраженные признаки РПП». Что это значит: здоровые установки; умение замечать эмоции; забота о себе. «Что дальше»: статьи / рекомендации / техники самопомощи.
- **Средний (жёлтый)**: «Некоторые ответы указывают, что стоит обратить внимание на отношения с едой, телом и эмоциями. Это не повод для паники — это сигнал, что забота о себе сейчас особенно важна». Что это значит: напряжение и тревога возможны; эмоции влияют на поведение; важно не оставаться одному. «Что дальше»: рекомендации / техники / статьи + мягкое упоминание разговора со взрослым, которому доверяешь.
- **Высокий (розовый)**: «Твои ответы указывают на выраженные признаки РПП и эмоционального дискомфорта. Это не диагноз, но важный сигнал: пожалуйста, не оставайся с этим один(на)». Что делать сейчас: обратись за помощью (взрослый, которому доверяешь, школьный психолог); не оставайся в одиночестве; заботься о себе бережно; двигайся маленькими шагами. **Телефоны помощи — сразу на экране** (см. раздел 6).

### 5.5. Техники самопомощи (`help.html`)

1. Заголовок + «Самопомощь — не замена профессиональной помощи, но важный шаг заботы о себе».
2. **Быстрые техники** — 5 карточек: Дыхание 4-7-8 · Заземление 5-4-3-2-1 · Самоподдержка (рука на сердце, тёплые слова себе) · Пауза и наблюдение («Сейчас мне тяжело, и это нормально») · Музыка и движение.
3. **Повседневная забота** — дневник мыслей, благодарность (3 вещи в день), режим сна, питание без строгих правил, маленькие радости.
4. **Напоминания** — «Ты не один(на)», «Твоя ценность не зависит от внешности», «Эмоции приходят и уходят», «Ошибки — часть пути», «Просить о помощи — нормально».
5. **Когда стоит обратиться за помощью** — 4 признака (тревога/грусть/вина мешают жить; мысли о причинении себе вреда; не справляешься долгое время; отношения с едой вызывают сильный стресс).
6. **#contacts «Куда обратиться»** — проверенные контакты (раздел 6) + совет про школьного психолога.

### 5.6. Статьи (`articles.html` + 3 статьи)

Список — 3 карточки (заголовок, 1–2 строки описания, время чтения).

1. **«Как поговорить с близким о РПП»** — полностью по референсу: подготовься (узнай о РПП; будь готов к разным реакциям; выбери время и место; проверь мотивы) → как начать («я-высказывания», говорить о чувствах, конкретно и деликатно, «я рядом») → поддерживающие фразы (6 из референса) → что важно помнить (слушай, не обесценивай, не дави, предложи помощь, заботься о себе) → куда обратиться.
2. **«Соцсети и образ тела»** (новая, тезисы): лента — не реальность (фильтры, ракурсы, отбор лучшего); сравнение с картинкой вредит самооценке; цифровая гигиена — отписаться от того, что заставляет чувствовать себя хуже, подписаться на доброе к телу; эксперимент «неделя без сравнений».
3. **«Еда и эмоции»** (новая, тезисы): заедание стресса — распространённый механизм, а не слабость; как отличить эмоциональный голод от физического; что делать вместо (пауза, техника из help), когда это повод поговорить со специалистом.

### 5.7. Рекомендации (`recommendations.html`)

Структура (тезисы): Питание без жёстких правил (регулярно, разнообразно, еда — забота, а не враг) · Сон и отдых · Движение в удовольствие, а не в наказание · Цифровая гигиена (см. статью про соцсети) · Доброта к себе (внутренний голос — как к другу) · Когда нужна поддержка → help.html. Внизу — CTA на тест и помощь.

## 7. Открытые решения, переходящие на этап «Дизайн»

- Фото (как в референсах) vs CSS/SVG-декор — влияет на вес страниц и лицензии.
- Локальный шрифт с открытой лицензией (кандидаты: Inter, Golos Text, Onest) — выбор на дизайне.
- Точный вид мини-визуализации факторов на результате (полоски vs 4 плашки).
