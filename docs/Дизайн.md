# Дизайн-система: сайт «Внутри себя»

Документ этапа 3. Основа — 8 референсов из `input/reference/` + решения ТЗ и Аналитики. Изображения: **без фотографий**, атмосфера строится SVG/CSS-декором (решение согласовано).

## 1. Дизайн-направление

Концепция: **«тихая комната»** — место, где можно выдохнуть. Светлый воздух, шалфейная зелень, мягкие поверхности, ничего резкого и «медицинского». Сайт разговаривает тихо и держит за руку: много белого, крупные бережные заголовки, тёплые акценты.

Три фирменные детали (то, что запомнится):
1. **Живая веточка** — рисованный SVG-мотив листьев (продолжение логотипа) дышит по углам секций.
2. **Точечная сетка** — деликатный dot-grid, перекочевавший из презентации Алисы: связывает сайт и доклад в один проект.
3. **Оживающая статистика** — число R «накручивается», полоски факторов растут на глазах: математика проекта видна буквально.

Чего не делаем: стоковые фото, кричащие цвета, тревожные красные экраны (даже «высокий риск» — тёплый розовый с заботливым текстом), резкие анимации.

## 2. Палитра (CSS-токены)

Значения выверены по референсам.

```css
:root {
  /* нейтрали */
  --bg:        #F2F4F5;  /* фон страницы, холодный светло-серый */
  --surface:   #FFFFFF;  /* карточки, шапка */
  --ink:       #2E3A43;  /* основной текст */
  --ink-soft:  #64737E;  /* вторичный текст */
  --line:      #E3E8EA;  /* разделители, рамки */

  /* акцент — шалфей/эвкалипт */
  --sage:      #6E8F7C;  /* иконки, ссылки, декор */
  --sage-deep: #52705F;  /* кнопки primary, заголовочные акценты */
  --sage-mist: #E7EFEA;  /* подложки иконок, hover */

  /* поддерживающие пастели (ротация плашек-иконок, как в референсах) */
  --lilac-mist: #ECEBF5;  /* блоки «важно помнить» */
  --sand-mist:  #F6EFE3;  /* тёплые акценты карточек */
  --sky-mist:   #E9F0F4;  /* информационные плашки */

  /* тёмная секция (CTA-полоса, как в референсах) */
  --pine:      #55685E;
  --pine-ink:  #F1F4F2;

  /* уровни риска: текст/акцент + светлая подложка */
  --low:       #4F8467;  --low-fill:  #E6F0EA;
  --mid:       #B8862F;  --mid-fill:  #F9F1DE;
  --high:      #C2536B;  --high-fill: #FAE9ED;
}
```

Правила: фон всегда `--bg`, контент на белых карточках; цветные — только акценты (иконки, плашки, полоски). Уровневые цвета появляются исключительно на экране результата и в его подложках. Контраст текста: `--ink` и уровневые тёмные оттенки на своих подложках проходят WCAG AA.

## 3. Типографика

| Роль | Шрифт | Насыщенность |
|---|---|---|
| Заголовки, логотип, число R | **Onest** | 500–700 |
| Текст, подписи, кнопки | **Golos Text** | 400/500/600 |

Обе семьи — кириллические, открытая лицензия OFL, скачиваются в `site/assets/fonts/*.woff2` (subset cyrillic+latin) на этапе MVP — никаких CDN. Фоллбэк: `system-ui, -apple-system, sans-serif`.

Шкала (fluid, clamp): display 40→56px/1.1 · h1 32→44 · h2 26→32 · h3 19→22 · body 16→17, межстрочный 1.65 · small 14. Число R на результате: Onest 600, 56→72px, `font-variant-numeric: tabular-nums`.

## 4. Пространство и форма

- Контейнер 1160px, боковые поля 20px (mobile) / 32px (планшет+). Вертикальный ритм секций 72→112px.
- Радиусы: карточки и hero-панели **24px**, вложенные карточки 16px, кнопки **14px**, чипы/плашки/прогресс — пилюля 999px. Шапка — белая скруглённая «капсула» с мягкой тенью (фирменный приём референсов).
- Тени: `0 10px 34px rgba(46,58,67,.07)` карточки; `0 16px 44px rgba(46,58,67,.10)` hover. Без жёстких контуров.
- Сетки карточек: 4 → 2 → 1 колонка (десктоп → планшет → мобайл).

## 5. Атмосфера и декор (вместо фото)

1. **Дымка**: 2–3 больших радиальных градиента на секцию (`--sage`/`--sky-mist`/`--lilac-mist`, непрозрачность 5–8%, blur не нужен — большие мягкие радиусы), в hero — обязательна.
2. **Зерно**: SVG `feTurbulence` поверх hero и тёмной CTA-полосы, opacity 2.5% — снимает «пластик».
3. **Веточки**: 3–4 рисованных SVG-мотива (эвкалипт, одиночные листья, изгиб стебля) в стиле логотипа; инлайн в HTML, stroke 1.5px, цвет `--sage` при 14–22% непрозрачности; позиционируются по углам hero, результата, тёмной полосы. На мобильных — уменьшаются или скрываются, чтобы не мешать тексту.
4. **Точечная сетка**: `background-image: radial-gradient(...)` точки 2px с шагом 18px, `--ink` при 6–8%; небольшие «пятна» сетки в углах секций — привет презентации.
5. Иконки: инлайн SVG, контурные, stroke 1.5–1.75px, скруглённые концы; сидят в плашках 48px с mist-подложками (ротация sage → lilac → sand → sky, как в референсах).

## 6. Компоненты

- **Шапка**: белая капсула (радиус 999), логотип-лист + «Внутри себя», меню из 5 пунктов, кнопка «Пройти тест» (primary, пилюля). ≤900px — бургер, меню раскрывается вниз внутри капсулы.
- **Кнопки**: primary — `--sage-deep`, белый текст, при hover темнеет + стрелка сдвигается на 3px; secondary — белая с рамкой `--line`; ghost — текст + стрелка. Высота 48px (44+ на мобильных).
- **Карточка-фича**: белая, иконка-плашка, заголовок 18–20px, 2–3 строки `--ink-soft`, стрелка-ссылка в углу.
- **Плашки доверия** (hero): строка из 3 мини-карточек с иконкой и двумя строками текста.
- **Радио-опция теста**: карточка-строка на всю ширину: кружок-радио, label 17px medium, hint 14px `--ink-soft`, контурная мини-иконка настроения справа (лист → волны → облако → дождь, как в референсе). Hover: рамка `--sage` 40%; checked: рамка `--sage-deep`, заливка `--sage-mist`, галочка в кружке. Вся карточка кликабельна.
- **Прогресс теста**: «Вопрос N из 29» + пилюля-трек 6px с заливкой `--sage-deep` (width transition) + процент справа + кнопка «Выйти из теста» (ghost).
- **Блок «важно помнить»**: лавандовая (`--lilac-mist`) карточка с иконкой-сердцем.
- **Тёмная CTA-полоса**: `--pine`, зерно, веточка 20%, текст + кнопка «Куда обратиться» (белая).
- **Результат — плашка уровня**: крупная иконка-сердце в круге `*-fill`, заголовок уровня цветом уровня, подпись; ниже — карточка «Твой показатель»: число R + «из 4» + **полоски факторов**: 4 строки (подпись F-фактора · трек 8px с заливкой цвета уровня · значение x.xx). 
- **Модалка подтверждения выхода**: маленькая белая карточка по центру, затемнение 30%, «Уйти» / «Остаться» (не системный alert).
- **Хлебные крошки**, **футер** (три колонки → стопка на мобильных), **карточка статьи** — по референсам.

## 7. Движение (простое, бережное)

| Момент | Анимация |
|---|---|
| Загрузка страницы | hero: стаггер fade + подъём 12px, шаг 80ms, 550ms, `cubic-bezier(.22,1,.36,1)` |
| Скролл | IntersectionObserver → `.in-view`: fade + подъём 16px, карточки стаггером 60ms |
| Смена вопроса | уходящий: fade+сдвиг 24px влево; входящий: справа (при «Назад» — зеркально), 300ms |
| Прогресс-бар | width 400ms ease-out |
| Экран результата | число R накручивается 0→значение ~900ms; полоски факторов растут стаггером 120ms |
| Hover | карточки: подъём 3px + тень; кнопки: затемнение + сдвиг стрелки |
| Выбор радио | короткий пульс рамки (scale 1→1.01→1, 200ms) |

`prefers-reduced-motion: reduce` → все переходы 0ms, счётчик и полоски показываются сразу, стаггеры отключены.

JS-минимум: IntersectionObserver, счётчик числа, переключение вопросов — всё в `main.js`/`quiz.js`, без библиотек.

## 8. Доступность

Фокус-кольцо 2px `--sage-deep` c offset 2px у всех интерактивных элементов; вопросы теста — `fieldset`+`legend`, варианты — настоящие `input[type=radio]`; прогресс — `role="progressbar"` с aria-значениями; цветовые уровни дублируются текстом; интерактивные цели ≥44px; `lang="ru"`, семантические лендмарки.

## 9. Соответствие референсам (сверка)

| Референс | Решение системы |
|---|---|
| Белая капсула-шапка с пилюлей CTA | компонент «Шапка» |
| Фото растений/свечей в hero | дымка + веточки SVG + зерно (решение «без фото») |
| Карточки с пастельными иконками | карточка-фича + ротация mist-подложек |
| Шкала ответов с иконками настроения | радио-опция с контурными мини-иконками |
| Три цветных экрана результата | токены `--low/--mid/--high` + плашка уровня |
| Тёмно-зелёная полоса «Если тяжело» | компонент «Тёмная CTA-полоса» |
| Dot-паттерн презентации | точечная сетка в декоре секций |

## 10. Что уходит на этап MVP

Скачивание и подключение Onest + Golos Text (woff2, subset), отрисовка 3–4 SVG-веточек и набора контурных иконок (~18 шт.), вёрстка компонентов по этому документу, тексты статей №2–3 и «Рекомендаций» из тезисов Аналитики.
