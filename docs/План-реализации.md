# План реализации MVP «Внутри себя»

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Рабочий статический сайт из 9 страниц с тестом на 29 вопросов, считающим риск РПП по формуле R = 0.25·F1 + 0.25·F2 + 0.3·F3 + 0.2·F4, без внешних зависимостей и без хранения данных.

**Architecture:** Чистая статика. Логика подсчёта (`quiz.js`: данные вопросов + `computeResult`) отделена от DOM-механики (`quiz-ui.js`) и покрыта Node-тестами без фреймворков. Стили — один `styles.css` на токенах из `docs/Дизайн.md`. Каждая страница — самостоятельный HTML с копией шапки/футера (без сборщика это осознанный выбор).

**Tech Stack:** HTML5, CSS (custom properties, grid/flex), vanilla JS (classic scripts — работают с `file://`), Node.js только для запуска тестов (`node:assert`). Шрифты Onest + Golos Text локально (variable woff2).

**Исходные документы:** `docs/ТЗ.md` (требования), `docs/Аналитика.md` (модель §3–4, контент §5, контакты §6), `docs/Дизайн.md` (токены §2, компоненты §6, движение §7).

**Git:** репозитория пока нет; коммиты появятся после согласованного `git init` (перед хостингом). Поэтому вместо шагов «commit» — шаги «проверка».

- [ ] **2.3** Реализовать в `site/js/quiz.js` (заменить заглушки):

```js
function levelFor(R) {
  return R < 1.5 ? "low" : R < 2.5 ? "medium" : "high";
}

function computeResult(answers) {
  const sums = { F1: 0, F2: 0, F3: 0, F4: 0 };
  const counts = { F1: 0, F2: 0, F3: 0, F4: 0 };
  for (const q of QUESTIONS) {
    const v = answers.get(q.id);
    if (typeof v !== "number") throw new Error("Нет ответа на вопрос " + q.id);
    sums[q.factor] += v;
    counts[q.factor] += 1;
  }
  const factors = {};
  for (const f in sums) factors[f] = sums[f] / counts[f];
  const raw = WEIGHTS.F1 * factors.F1 + WEIGHTS.F2 * factors.F2 +
              WEIGHTS.F3 * factors.F3 + WEIGHTS.F4 * factors.F4;
  // Классифицируем по округлённому до 2 знаков значению: пользователь видит
  // «2.50» — уровень обязан соответствовать показанному числу (без сюрпризов
  // от плавающей точки на границах 1.5 / 2.5).
  const R = Math.round(raw * 100) / 100;
  return { R, factors, level: levelFor(R) };
}
```

```js
  }
  function onSelect(value) { state.answers.set(currentQuestion().id, value); /* enable next */ }
  function next() { /* index < 28 ? (index++, renderQuestion("fwd")) : showResult() */ }
  function back() { /* index--, renderQuestion("back") */ }
  function showScreen(id) { /* hidden у всех .screen, кроме id; scroll to top */ }
  // exit: показать #exit-modal; start: showScreen("scr-quiz") + renderQuestion()
})();
```

Правила: «Далее» — единственный путь вперёд (сабмит формы Enter'ом тоже вызывает `next` через `submit`-обработчик с `preventDefault`); выбор кликом по всей карточке (label). Никакой записи в storage.
