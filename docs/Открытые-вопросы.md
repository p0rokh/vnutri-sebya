# Открытые вопросы по модели (решает Алиса)

Константы лежат в `site/js/quiz.js`. После изменения — пересчитать контрольные примеры в `docs/Аналитика.md` §3.5 и `tests/quiz.test.js`, прогнать `tests/smoke.html`. Собранные ответы пересчитывать не нужно: на сервер уходит индекс варианта, а не балл.

## 1. Пороги уровней риска на шкале 1–5

Было (шкала 1–4): низкий < 1.5, средний < 2.5, высокий ≥ 2.5.
Сейчас в коде (**временно**): `LEVELS = { mediumFrom: 1.67, highFrom: 3.0 }` — пропорциональный перенос тех же долей шкалы.
Альтернатива: круглые 2.0 / 3.0 — проще объяснять на защите, но больше людей попадёт в «низкий».
⚠️ Пока вопрос не решён, сайт показывает уровни по временным порогам.

## 2. Баллы для q29 «В семье есть люди с проблемами питания или веса» (Да/Нет)

Сейчас: Да = 5, Нет = 1 (вопрос остаётся в F4, как в презентации).
Альтернатива: исключить из подсчёта (`factor: null`), оставить только для статистики.

## 3. Баллы для q30 «Сколько человек в твоём окружении имеют проблемы с отношением к еде?»

Сейчас: Ни одного = 1, 1–2 = 2, 3–5 = 4, Более 5 = 5.
Альтернативы: 1/2/3/4 (как в старой модели) или 1/2/3/5.

## 4. «Вы» и «ты» в формулировках

Вопросы 1, 2, 32, 33 — на «вы», вопросы 30–31 — на «ты», весь остальной сайт — на «ты». Оставлено дословно как в итоговом списке.

## 5. Пропуски и «затрудняюсь» в подсчёте
