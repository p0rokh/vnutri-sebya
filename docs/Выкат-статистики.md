# Выкат опросника v2 и статистики — пошагово

Ветки: `feature/survey-v2` (опросник) и `feature/stats-backend` (бэкенд, включает первую).
Выполнять по порядку. Шаги 1–5 — на сервере под root (`ssh root@insideoneself.orbitalfeed.ru`).

## Шаг 0. Локально: выкатить код в main

```bash
cd ~/Repository/edata-ai
git checkout main
git merge feature/stats-backend      # fast-forward, тянет и опросник v2, и бэкенд
git push origin main
```

Через 5 минут сайт обновится сам. До шага 2 страница `/stats.html` будет лежать открытой,
но без API она пустая, данных там нет — безопасно.

⚠️ Вместе с этим уезжает опросник с **временными** порогами уровней 1.67 / 3.0
(см. `Открытые-вопросы.md` §1).

## Шаг 1. Сервер: HTTPS и пакет

```bash
ssh root@insideoneself.orbitalfeed.ru
certbot --nginx -d insideoneself.orbitalfeed.ru --redirect --agree-tos -m a87skorolev@gmail.com --no-eff-email
apt-get install -y apache2-utils
```

## Шаг 2. Сервер: дождаться деплоя и подключить конфиги

```bash
deploy-vnutri-sebya                    # подтянуть main руками, не ждать таймер
ls /opt/vnutri-sebya/server            # должны быть app.py, nginx-api.conf и т.д.

cp /opt/vnutri-sebya/server/nginx-limits.conf /etc/nginx/conf.d/vnutri-sebya-limits.conf
cp /opt/vnutri-sebya/server/nginx-api.conf   /etc/nginx/snippets/vnutri-sebya-api.conf
cp /opt/vnutri-sebya/server/vnutri-sebya-api.service /etc/systemd/system/

# include внутрь server-блока (перед location /)
sed -i 's#^\(\s*\)location / {#\1include snippets/vnutri-sebya-api.conf;\n\n\1location / {#' /etc/nginx/sites-available/vnutri-sebya
grep -n "include snippets/vnutri-sebya-api" /etc/nginx/sites-available/vnutri-sebya   # ровно одна строка
```

**Пароль статистики** (логин `stats`, команда сама спросит пароль):

```bash
htpasswd -c /etc/nginx/vnutri-sebya.htpasswd stats
chown root:www-data /etc/nginx/vnutri-sebya.htpasswd && chmod 640 /etc/nginx/vnutri-sebya.htpasswd
nginx -t && systemctl reload nginx
```

## Шаг 3. Сервер: запустить API

```bash
systemctl daemon-reload
systemctl enable --now vnutri-sebya-api.service
curl -s 127.0.0.1:8765/api/health        # {"ok": true}
systemctl status vnutri-sebya-api --no-pager | head -5
```

## Шаг 4. Сервер: обновить deploy-скрипт

Чтобы бэкенд перезапускался при изменениях в `server/`, заменить скрипт целиком:

```bash
cat > /usr/local/bin/deploy-vnutri-sebya <<'EOF'
#!/usr/bin/env bash
set -euo pipefail
REPO=https://github.com/p0rokh/vnutri-sebya.git
DIR=/opt/vnutri-sebya
WEBROOT=/var/www/vnutri-sebya

if [ ! -d "$DIR/.git" ]; then
    git clone --depth 1 --branch main "$REPO" "$DIR"
fi
git -C "$DIR" fetch --depth 1 origin main
OLD=$(git -C "$DIR" rev-parse HEAD)
if [ "$OLD" != "$(git -C "$DIR" rev-parse origin/main)" ] || [ ! -f "$WEBROOT/index.html" ]; then
    git -C "$DIR" reset --hard origin/main
    mkdir -p "$WEBROOT"
    rsync -a --delete "$DIR/site/" "$WEBROOT/"
    if ! git -C "$DIR" diff --quiet "$OLD" HEAD -- server/ 2>/dev/null; then
        systemctl try-restart vnutri-sebya-api.service || true
    fi
    echo "$(date -Is) deployed $(git -C "$DIR" rev-parse --short HEAD)"
fi
EOF
chmod 755 /usr/local/bin/deploy-vnutri-sebya
```

## Шаг 5. Проверки

```bash
curl -s -o /dev/null -w "%{http_code}\n" https://insideoneself.orbitalfeed.ru/api/stats     # 401
curl -s -o /dev/null -w "%{http_code}\n" https://insideoneself.orbitalfeed.ru/stats.html    # 401
curl -s -o /dev/null -w "%{http_code}\n" -X POST -H "Content-Type: application/json" -d '{}' https://insideoneself.orbitalfeed.ru/api/results   # 400 — запрос дошёл до бэкенда
```

Затем в браузере: `https://insideoneself.orbitalfeed.ru/stats.html` → логин `stats` + пароль.
Пройти тест на сайте и убедиться, что ответ появился на странице статистики.

## Пароль локально, в Keychain

На маке (команда спросит пароль сама):

```bash
security add-generic-password -a "$USER" -s vnutri-sebya-stats -w
```

Достать потом: `security find-generic-password -a "$USER" -s vnutri-sebya-stats -w`.

## Если что-то пошло не так

- Логи API: `journalctl -u vnutri-sebya-api -n 50`
- Логи деплоя: `journalctl -u vnutri-sebya-deploy.service -n 20`
- Конфиг nginx: `nginx -t`, после правок `systemctl reload nginx`
- Откатить API, не трогая сайт: `systemctl disable --now vnutri-sebya-api` — фронт продолжит работать,
  отправка результатов будет молча падать.
- Бэкап базы: `python3 -c "import sqlite3; sqlite3.connect('/var/lib/vnutri-sebya/results.db').backup(sqlite3.connect('/root/results-$(date +%F).db'))"`
